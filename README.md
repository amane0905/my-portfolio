# My Portfolio

Webフロントエンド（HTML / CSS / JavaScript）と Firebase を使って制作したアプリをまとめたポートフォリオです。
「使う人が安心できる、温かみのあるデザイン」を大切にしながら、認証・データベース・リアルタイム通信などの機能実装に挑戦しました。

## 使用技術（全体）

- **フロントエンド**：HTML / CSS / JavaScript（フレームワークを使わずに実装）
- **バックエンド（BaaS）**：Firebase Authentication / Cloud Firestore
- **リアルタイム通信**：WebRTC（Firestore をシグナリングに利用）
- **公開**：GitHub Pages
