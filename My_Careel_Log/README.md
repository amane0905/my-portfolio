# 📔 MY CAREER LOG

**インターンや企業研究を通して「自分を知る」ための、就活ノートアプリです。**

所属している就活ゼミの1週間インターンで、**ゼミのメンバーみんなが使えるように**個人で開発したアプリです。

就活では企業のことは調べても、「その企業を見て自分が何を感じたか」は記録に残りにくいと感じていました。
このアプリでは、企業ごとのメモに加えて、そのとき感じた気持ちや気づいた価値観を残し、少しずつ自分の軸が見えてくることを目指しています。

## 使い方

1. **ログイン**：Google アカウントでログインします。
2. **企業ノートを書く**：「＋ 企業ノートを書く」から、企業情報・インターンの内容・感想を記録します。感じたこと（楽しかった、悔しかった など）はボタンで選べます。
3. **星評価と価値観タグ**：企業に星評価をつけ、気づいた価値観をタグとして残します。
4. **振り返る**：「ランキング」で今の自分が惹かれる企業を、「MY VALUES」で集まった価値観を確認できます。
5. **経験を記録する**：「キャリアログ」に、就活以外の経験も時系列で書きためられます。
6. **7日間の私**：1週間を振り返り、自分について気づいたことを記録します。
7. **先生からのコメント**：「矢島コメント」タブで、ゼミの先生からのフィードバックを確認できます。
8. **データの持ち帰り**：記録はファイルとして書き出し・読み込みができます。

---

## 主な機能

- Google ログイン（Firebase Authentication）
- 企業ノート（企業情報・感想・星評価・価値観タグ）
- 惹かれる企業のランキング表示
- 価値観（MY VALUES）の一覧
- キャリアログ（経験の時系列記録）
- 「7日間の私」振り返り
- やりがい広場
- 先生（メンター）からのフィードバック機能：学生の記録に先生がコメントを書き込み、学生はそれを読んで振り返れます（Firestore）
- データのエクスポート / インポート

## 工夫した点

- **感情を記録しやすくする工夫**：自由記述だけだと書くのが負担になるため、気持ちをボタンで選べるようにしました。
- **価値観の見える化**：企業ノートで付けたタグを集約し、自分が大事にしていることが自然に見えてくるようにしました。
- **先生と学生で権限を分ける**：ログインしたアカウントによって、先生はコメントを編集でき、学生は閲覧のみになるよう切り替えています。
- **データの持ち帰り**：自分の記録を手元に残せるよう、書き出し・読み込み機能を付けました。
